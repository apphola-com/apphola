# 霍拉应用（Hola Apps）

> 本地优先的 Windows 效率工具箱 · **29 个工具**（12 个免费 + 17 个会员）· 默认离线运行，数据留在你的电脑

English: [`README.en.md`](./README.en.md)

## 简介

霍拉应用是一款为 Windows 打造的本地优先效率工具合集，覆盖剪贴板、截图、文件、系统、网络与翻译六大场景。快捷键与全局搜索驱动，托盘常驻、随叫随到，安装即用、打开即用；**绝大多数工具完全离线可用**。

**官网**：<https://www.apphola.com/>

**本仓库仅发布生产打包文件**（见 [Releases](https://github.com/apphola-com/apphola/releases)），不含源码。

## ✨ 功能特性

29 个工具按六大类别组织（★ = 会员专属功能，登录账号即可解锁）：

### 输入 · Input

- 超级剪贴板
- 文本模板（代码片段）
- 便签 / 待办
- ★ 文本 / 编码工具箱
- ★ 正则测试器
- ★ 文本 / 文件对比

### 采集 · Capture

- 截图与贴图
- 文件预览（图片 / PDF / 代码 / 压缩包）
- 屏幕取色器
- ★ 离线文字识别（OCR）

### 窗口 · Window

- 快捷键总控
- 系统监控浮窗
- ★ 系统信息报告
- ★ 鼠标高亮 / 聚光灯
- ★ 番茄钟 / 专注计时

### 文件 · File

- 文件哈希校验
- ★ 批量重命名
- ★ 图片压缩 / 格式转换
- ★ 重复文件查找
- ★ 隐私清理 / 文件粉碎
- ★ 定时执行命令
- ★ 文件加密 / 解密（AES-256）
- ★ 定时备份 / 文件同步

### 网络 · Network

- 定时任务
- ★ 局域网快传（不走公网）
- ★ 二维码生成
- ★ 网络端口检测

### AI 与翻译 · AI

- AI 翻译（需配置 AI 模型）
- 机器翻译（需配置阿里云 AccessKey，支持 214 种语言互译）

## ⚙️ 全局配置中心

一次填写，所有工具共享，避免在每个工具里重复录入密钥：

- **阿里云对象存储（OSS）**：Endpoint、Bucket、Region、AccessKey 等
- **阿里云 AccessKey**：AccessKey ID + AccessKey Secret（供机器翻译等使用）
- **AI 模型**：Base URL、API Key、模型（**OpenAI 兼容**模式）

## 🚀 下载与安装

1. 前往 [Releases](https://github.com/apphola-com/apphola/releases) 页面。
2. 下载最新版本的安装包（`*.exe` 或 `*.msi`）。
3. 运行安装包完成安装；首次运行如需 WebView2 运行时会自动引导安装。

> 安装包为 **生产打包（Release）构建**，仅包含最终产物。

## 🔒 隐私与本地优先

- **本地优先**：绝大多数工具完全离线运行（剪贴板、截图、取色、OCR、哈希校验、文件加密、批量重命名、图片处理、隐私清理、备份等），数据默认只保存在本机。
- **需要联网的功能**仅以下三项，且都使用**你自行配置的账号与密钥**，不配置就不会发起任何请求：
  - 会员登录与订阅
  - AI 翻译（OpenAI 兼容接口）
  - 机器翻译（阿里云机器翻译）
- 除上述功能外，应用不会自动上传任何数据。
